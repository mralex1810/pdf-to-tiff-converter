# Автономная HTML-версия

Готовый `PdfToTiff.html` открывается двойным щелчком в актуальном Edge/Chrome.
Сервер, интернет, Node.js и .NET пользователю не нужны. Все ресурсы PDF.js
встроены в HTML; CSP запрещает сетевые соединения. PDF читается только через
выбор файла/перетаскивание. Сценарии внутри PDF не исполняются.

По умолчанию: отдельный TIFF на страницу, 400 DPI, чёрно-белый (1 бит), PackBits, скачивание ZIP.
Многостраничный TIFF, 200/300/400/600 DPI, цветной/серый/1-битный режим, PackBits/LZW/без сжатия —
в настройках. «Как скачать страницы» позволяет выбрать ZIP или отдельные
TIFF-файлы без архива. В режиме файлов есть общая кнопка и ссылка на каждую
страницу: браузер может ограничить несколько автоматических скачиваний.
Многостраничный TIFF всегда скачивается одним файлом.
CCITT Group 4 и Deflate остаются в Windows-приложении.
Под кнопкой скачивания показаны местные дата и время создания текущего результата.
Время обновляется после успешной конвертации, при повторном скачивании остаётся
прежним и очищается вместе с результатом.
Все исходные документы и предыдущие скачивания сохраняются.

## Самостоятельная сборка

Нужны Node.js 22.13+ и npm. Из корня репозитория:

```sh
cd web
npm ci --ignore-scripts
npm run build
```

Первая загрузка пакетов требует интернет. Результат —
`artifacts/html/PdfToTiff.html`, `PdfToTiff-html.zip` и их `.sha256`.
ZIP содержит тот же HTML, инструкцию и лицензии. HTML самодостаточен:
его можно копировать отдельно, лицензии также встроены в него.
Сборка не обращается к CDN; версии зафиксированы в `package-lock.json`.

## Проверки

```sh
# В каталоге web
python -m pip install -r test/requirements.txt
npm test
npx playwright install chromium
npm run test:browser
```

`TIFF_TEST_PYTHON` позволяет указать путь к Python с Pillow.
Без Pillow независимый тест будет отмечен как пропущенный; в CI он обязателен.
На Windows с установленным Edge:

```powershell
$env:PDF_TO_TIFF_BROWSER = 'msedge'
npm run test:browser
```

Для локального PDF дополнительно задайте `PDF_TO_TIFF_SAMPLE` полным путём;
в CI используются только синтетические документы. Исходный PDF никуда не
загружается и не попадает в сборку.

Тест браузера открывает **готовый HTML через file://**, отключает сеть и
контролирует отсутствие HTTP(S)-запросов. Проверяются настройки, настоящий
рендер, отдельные/многостраничные TIFF, DPI, пиксели, сохранённые AcroForm,
отмена, восстановление после ошибок, отказ от пароля/XFA, JPEG2000 и CCITT Group 4 внутри PDF. Результаты, снимок окна и
отчёт: `artifacts/html-tests/`.

## Устройство и ограничения

`src/main.js`: PDF.js → Canvas RGBA; `src/tiff.js`: собственный полосовой
TIFF-кодировщик с PackBits и LZW; `src/ui.js`: интерфейс; fflate создаёт ZIP.
`scripts/build.mjs` собирает приложение, встраивает worker, CMaps, шрифты,
WASM-кодеки и ICC-профиль. Проверяемые изменения PDF.js заменяют загрузку
ресурсов чтением встроенных байтов, включая запасные шрифты. Worker собирается
как обычный скрипт: module worker из Blob не запускается в проверенном режиме
file:// без сети. При изменении версии PDF.js патчи требуют повторной проверки.

PDF до 128 МиБ; страница до 80 млн пикселей; суммарно до 256 МиБ RGBA.
Оставшийся бюджет проверяется перед созданием canvas. Реальная память выше
из-за PDF.js, canvas, кодирования и финального архива. Для больших PDF
используйте нативную версию. Отмена — между операциями.

PDF с паролем и XFA не поддерживаются. Сохранённые обычные поля AcroForm
рендерятся; интерактивный пересчёт не выполняется. Невстроенные шрифты могут
заменяться системными или встроенными запасными. Браузерное и нативное
растеризованные изображения могут не совпадать побитно.
