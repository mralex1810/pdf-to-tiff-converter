PDF → TIFF — Windows 10/11 x64

1. Полностью распакуйте ZIP в обычную папку.
2. Запустите PdfToTiff.exe. Установка .NET и доступ в интернет не нужны.
3. Выберите PDF и папку результата.
4. Нажмите «Конвертировать».

По умолчанию каждая страница сохраняется отдельным TIFF: имя_001.tiff,
имя_002.tiff и т. д. Настройка «Страницы» позволяет выбрать один
многостраничный TIFF. Начальные настройки: 200 DPI, цветной, LZW.

Каждый запуск создаёт новую подпапку результата. Исходный PDF и ранее
созданные файлы не перезаписываются. Документы никуда не отправляются.

Для чёрно-белого режима доступно сжатие CCITT Group 4 и порог яркости.
При таком преобразовании полутона исчезают; проверьте светло-серые подписи.

PDF с паролем нужно предварительно сохранить без пароля. XFA-формы
следует сначала преобразовать в обычный PDF. Сохранённые поля AcroForm
отрисовываются; JavaScript и пересчёт полей не выполняются.

Отмена может дождаться окончания отрисовки текущей страницы.
Лимиты: PDF до 512 МиБ, до 80 млн пикселей на страницу, DPI от 72 до 600.
Для большого многостраничного TIFF выберите отдельные файлы.

Portable-пакет содержит EXE и необходимые DLL рядом с ним. Не переносите
только EXE: сохраняйте всё содержимое распакованной папки вместе.
При обычной сборке библиотеки не извлекаются во временную папку.
Права администратора для запуска не нужны.

Если окно не появилось, запустите «Запуск с диагностикой.cmd».
Журналы запуска находятся в %LOCALAPPDATA%\PdfToTiff\Logs.
Диагностический запуск открывает обычное окно приложения.

Лицензии сторонних компонентов находятся в папке licenses.
